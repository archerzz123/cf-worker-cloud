# PubAPI LLM Access Guide

This endpoint set is OpenAI-compatible and supports direct calls from LLM clients.

## Base URL
- https://cloud.gwvbrmrj265-jelia.workers.dev

## Authentication
- Send API key via one of:
  - Authorization: Bearer <API_KEY>
  - X-API-Key: <API_KEY>
  - query: ?api_key=<API_KEY>
- Required for all endpoints except OPTIONS, /v1/models, /llm.txt

## OpenAI-Compatible Endpoints
- GET /v1/models
- POST /v1/chat/completions
- POST /v1/audio/speech
- POST /v1/images/generations

## RESTful API Usage
- Route pattern: /api/{provider}/{action}
- Supported REST routes:
  - /api/gg/translate
  - /api/gg/dict
  - /api/gg/tts
  - /api/iciba/dict
  - /api/iciba/suggest
  - /api/youdao/dict
  - /api/youdao/suggest
  - /api/ms/translate
  - /api/pollinations/image
- Common params:
  - text: string (required in most routes)
  - source_lang: string, default=auto
  - target_lang: string, default=en
  - speed: number, default=1
  - type: number, default=1 (1=UK, 2=US for dict voice providers)
  - nums: number, default=5
  - width: number, default=1024 (image routes)
  - height: number, default=1024 (image routes)

### Response schema
- JSON routes (translate/dict/suggest):
  {
    "text": "string",
    "raw": "object|array"
  }
- Audio routes (tts):
  - binary audio stream
  - content-type: audio/mpeg
- Image routes:
  - /api/pollinations/image returns binary image data
  - /v1/images/generations returns {"created": number, "data": [{"url": string}]} by default
  - /v1/images/generations with response_format=b64_json returns {"created": number, "data": [{"b64_json": string}]}

### Error schema
  {
    "error": "string",
    "status": "number",
    "code": "string",
    "request_id": "string",
    "details": "optional"
  }

### RESTful Examples
- GET /api/gg/translate?text=hello&target_lang=zh-CN
- GET /api/iciba/dict?text=example
- GET /api/youdao/suggest?text=do&nums=5
- POST /api/ms/translate
  {"text":"hello world","source_lang":"en","target_lang":"zh-Hans"}
- GET /api/gg/tts?text=hello&target_lang=en&speed=1
- GET /api/pollinations/image?text=a%20cat&width=1024&height=1024
- POST /v1/images/generations
  {"model":"pollinations-image","prompt":"a cat","width":1024,"height":1024,"response_format":"url"}
